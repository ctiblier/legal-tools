## Watch out for

- **Pushing `main` deploys.** Push only after the review's fixes are in.
- **Worker tests lean towards asserting the worker's own output.** For each worker test, ask
  whether it would fail on the plausible wrong answer, then break the code and watch it go red.
  All CONFIRMED in `check_claims.py` means reproducible, not correct.
- **Missing paths on the live site return the homepage with HTTP 200**, so check the body.
- **`networkidle` never fires on the live page**: use a fixed wait.
- **Playwright MCP is broken here.** Drive Chromium directly:
  `require('/home/ctibs/.npm/_npx/86170c4cd1c5da32/node_modules/playwright')` with
  `executablePath` set to
  `~/.cache/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`.
  Driver scripts from this session are in the session scratchpad (gone); rewrite as needed.
- **Never `pkill -f`**: kill servers by PID via `lsof -ti :<port>`.
- **Root `shared/` is source; `batesstamp/shared/` is build output.** The worker in `eml-sizewarn`
  created `batesstamp/dev/`. It was deleted, but confirm a plain build leaves no `batesstamp/dev`.
- **Local workers run one at a time on Flash-Next.** Dispatch with Bash `run_in_background`,
  never `&`.
