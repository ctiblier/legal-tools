## Watch out for

- **Any change to what a page loads must pass `dev/csp/run`** before pushing. A wrong CSP fails silently for
  users. New or upgraded CDN files need their exact URL added to `_headers`. No inline `<script>` and no
  `on*=` attributes.
- **`dev/csp/run` cannot see violations inside workers.** Its test PDF uses only a standard font.
- **curl does not follow `/x.html` → `/x` redirects** unless you pass `-L`. A missing path returns the homepage
  with a 200, so check the body.
- **Pushing `main` deploys.** Get an independent Opus review before each push, including for your own fixes.
- **Playwright MCP is broken here.** `dev/csp/e2e.js` shows how to drive Chromium directly.
- **Never `pkill -f`.** Kill by PID (`lsof -ti :<port>`).
- **Unit suite:** `cp docs/closeouts/2026-09-14-0841-run-tests.sh /tmp/run-tests && PORT=8792 /tmp/run-tests`.
  Run `python3 docs/fixtures/eml/generate.py` first, and finish with `bash build.sh` so the tree is a
  plain build.
- **Certificate text is evidence.** Bump `shared/eml/version.js` on any change to its wording or to conversion.
