## Watch out for

- **A fixture that cannot expose a defect is not coverage.** This is the single
  most expensive lesson of the whole project, and it bit twice more this session:
  the footer-overprint checklist item pointed at fixture 07, whose attached PDF is
  6 MB of blank padding, so it could never fail; and the certificate's substitution
  count was recorded green at **26** when the true answer is **13**. Before
  trusting any green item, check the fixture actually contains the thing being
  looked for.
- **Tests that cannot fail remain the dominant defect class** — found six times
  during construction and six more across the last two sessions. Four were fixed
  this session, including one asserting only `bytes.length > 1000` (passes for a
  blank document) and one that skipped itself via an early return. If a test looks
  like coverage, break the behaviour it names and confirm it goes red.
- **pdf.js transfers the buffer it is handed** to its worker, detaching it. A
  second `getDocument` on the same bytes sees an empty array. Pass `.slice()` when
  the bytes are needed twice — this cost a confusing red herring last session.
- **pdf-lib's `scaleContent()`/`translateContent()` wrap the whole content stream**,
  so anything drawn afterwards is transformed too. That is why attachment pages are
  drawn as form XObjects instead of copied and transformed.
- **Playwright MCP is broken on this host** — it wants a Chrome channel at
  `/opt/google/chrome/chrome` that is not installed. Drive the browser with a
  direct script against the cached Chromium at
  `/home/ctibs/.npm/_npx/86170c4cd1c5da32/node_modules/playwright` instead. That is
  how all of this session's real verification was done.
- **Never `pkill -f`** on this host — it matches its own command line. Kill by PID
  via `lsof -ti :8788`. (CLAUDE.md records two Pingvin outages from this.)
- **Root `shared/` is the source of truth.** `batesstamp/shared/` is gitignored
  build output that `build.sh` overwrites. `batesstamp/email-to-pdf/index.html`,
  however, **is** tracked source — edit it directly.
- **`build.sh --dev` is dev-only.** Pages runs plain `bash build.sh`, which now
  also clears any fixtures a previous `--dev` build staged.
