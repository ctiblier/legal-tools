## Watch out for

- **`origin/main` is 3 commits behind local `main`.** The spec, plan and
  adversarial-fix commits are local-only. The worktree was created from
  `origin/main` and came up without the spec or plan; it had to be reset onto local
  `main`. Check this before any push or rebase.
- **Never `pkill -f`** on this host — it matches its own command line. Kill by PID
  via `lsof -ti :8788`. (CLAUDE.md records two Pingvin outages from this.)
- **Root `shared/` is the source of truth.** `batesstamp/shared/` is gitignored build
  output that `build.sh` overwrites; editing it produces a change that works locally
  and vanishes on the next build.
- **`build.sh --dev` is dev-only** — it stages evidence fixtures into the served
  root. Cloudflare Pages runs plain `bash build.sh`. Never deploy a `--dev` build.
- **This branch adds ~5.6 MB** (4.1 MB fonts + ~1.5 MB vendored JS) to a static-site
  repo. Worth a conscious yes before merging.
- **Tests that cannot fail were this project's dominant defect class** — found six
  times. If a test looks like coverage, check it can actually go red before trusting
  it.
