## Pending work

1. **File-pick race** — `batesstamp/email-to-pdf/index.html`. Files chosen before
   the module script attaches its `change` listener are ignored and Convert stays
   disabled. On module init, if `#fileInput.files.length`, process them.
   Reproduce by setting input files immediately after `goto` against the live site.
2. **SRI for JSZip on the Bates Stamp page** — `batesstamp/bates-stamp/index.html`.
   Hash: `sha384-+mbV2IY1Zk/X1p/nWllGySJSUN8uMs+gUAN10Or95UBH0fpj6GfKgPmgC5EXieXG`
   (verified identical on unpkg and jsDelivr). Check its other CDN scripts too.
3. **Disclose renamed ZIP entries** on the certificate (`zipEntryName` in
   `shared/eml/filename.js` renames silently; `appendAttachments` in
   `shared/eml/assemble.js` knows both names).
4. **Remaining Importants from September:** `MAX_WARN_MB` unused (implement the
   spec's 25 MB warning or delete); `rowspan` not honoured/disclosed; the
   "script or style element(s)" certificate count includes `meta`/`form`/etc.;
   combined path holds every record in memory.
5. Optional: site-wide CSP with `connect-src 'self'` — touches every page and the
   Umami/Cloudflare beacons, so needs an owner decision first.

## Watch out for

- **Pushing `main` deploys.** Pages builds from it within ~45s.
- **Missing paths on the live site return the homepage with HTTP 200**, so a
  status code proves nothing — check the body.
- **`networkidle` never fires on the live page** (something keeps retrying);
  use a fixed wait in Playwright drivers.
- **Playwright MCP is broken here** — drive the cached Chromium directly via
  `/home/ctibs/.npm/_npx/86170c4cd1c5da32/node_modules/playwright` with
  `executablePath` set to the headless shell under `~/.cache/ms-playwright/`.
- **Tests that cannot fail** remain the dominant defect class: break the behaviour
  and watch the test go red before trusting it. One of this session's own tests
  initially asserted "no digit 2", which the SHA-256 in the text always violated.
- **pdf-lib's `asRectangle` does not normalise corner order**; read raw box arrays.
- **Never `pkill -f`**; kill servers by PID via `lsof -ti :<port>`.
- **Root `shared/` is source**; `batesstamp/shared/` is build output. Test-only
  files are tracked in `dev/` and staged only by `build.sh --dev`.
