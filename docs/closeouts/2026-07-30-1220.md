## Decisions Made

- **Font rules live in `batesstamp/fonts.css`, not `shared/brand.css`** —
  brand.css is also consumed by pfscalculator.com, which has no `/fonts/`
  directory; putting `@font-face` there could shadow pfscalculator's working
  Google-Fonts faces with 404ing sources. **pfscalculator still loads Google
  Fonts** — migrate separately if desired.
- **PDF→Word converter: recommended against building.** Word already converts
  PDFs locally (File → Open), so the privacy differentiator evaporates; browser-JS
  reconstruction quality would sit below what every lawyer already owns; and a
  tool with always-imperfect output breaks the site's "deterministic — works or
  visibly fails" trust model. Suggested alternatives: a guide page teaching the
  Word trick (SEO play), or deterministic tools Word can't do (in-browser OCR via
  Tesseract.js, PDF/A converter). User is still hunting for a quality client-side
  conversion library.
- Kept latin + latin-ext subsets only (matches Google's own subsetting for this
  site's charset use; italics remain browser-synthesized, same as before).
