## Decisions Made

- **Appended attachment pages are scaled to ~94%, not overprinted** (owner ruling,
  offered three options). Continuous `page n of N` across the whole exhibit is what
  lets a loose page be placed back, so the footer stays on every page; the
  attachment is reduced and centred to make room, nothing is cropped or hidden, and
  the reduction is disclosed on the certificate as `ATTACHMENT_SCALED`.
- **Attachment pages are drawn as form XObjects rather than copied.** pdf-lib's
  `scaleContent()`/`translateContent()` wrap the page's *whole* content stream, so
  a footer drawn afterwards is scaled and shifted along with it and lands back in
  the band it was meant to avoid. Verified empirically before switching approach.
- **`/Rotate` must be passed in explicitly.** Confirmed by dialling both pdf-lib
  paths directly: source `/Rotate 90`, `copyPages` → 90, `embedPdf` → 612x792
  (unrotated) with drawn rotation 0. This was a regression introduced by the
  XObject switch earlier the same day and caught by the review, not by me.
- **Substitution counting is opt-in, and only the drawing path opts in.**
  `segment()` is called to measure as well as to draw — once per token while
  wrapping, once per character inside `hardBreak()` against a growing buffer — so
  counting on every call inflated the figure 2x in the simple case and
  quadratically for a long unbreakable token.
- **The corrupt-file checklist item was left unchecked rather than rewritten.**
  200 random bytes convert rather than failing: RFC 822 has no magic bytes, so
  postal-mime accepts any byte string. Nothing is concealed — the certificate says
  "Body rendered from no body part", the appendix reproduces the raw bytes — but
  the item as written predicts a red failure row, and that is not what happens.
  Whether an unparseable file should be *refused* rather than disclosed is a
  product decision, not a bug to paper over.
- **`EML_TOOL_VERSION` left at `1.0.0`.** Conversion behaviour genuinely changed,
  which by the stated rule wants a bump — but the tool has never shipped, so 1.0.0
  is still the first released version. Flagged, not decided.
- **Merge deliberately not performed.** Cloudflare Pages builds from `main`, so
  landing these commits there publishes to the live site. The decision was put to
  the owner and is still open.

## What the Review Found (all four Criticals verified, then fixed)

1. **The certificate's substitution count was inflated 2x**, quadratically for long
   tokens. Fixture 05's CJK sentence 契約書の翻訳を添付します。 is 13 characters;
   the certificate said 26 — **and this closeout's own checklist had already
   recorded 26 as green.** A plausible-looking number survived a manual read.
2. **Every certificate in a combined PDF reported a running document total** for
   "Pages of message content" — a field whose own parenthetical says it excludes
   the certificate, manifest and appendix. Measured 5 and 8 for two one-page
   messages in an 8-page exhibit.
3. **Combined certificates attributed other messages' limitations to the wrong
   message.** Proven with a probe ordering an image-blocking message first: the
   second message, plain text with no images at all, carried a certificate
   asserting "2 remote image(s) were not loaded, of which 1 were tracking pixels."
   A false statement of fact on an authenticating document.
4. **`/Rotate` was silently dropped**, so a landscape scan stored as a portrait
   MediaBox — what scanners and fax gateways produce — appended upright and fitted
   against the wrong box.
