## Decisions Made

- **Version bumps:** 1.0.0 → 1.1.0 (table layout and certificate text), then 1.2.0 (attachment
  numbers and the ZIP folder line). `version.js` says to bump whenever conversion output changes.
- **Every Claude fix got its own review before each push.** It was worth it: two rounds found
  real hangs in my own fixes.
- **Bound the input rather than optimise the data structure.** Interval storage alone still cost
  live spans × rows, so the limits (`MAX_COLUMNS`, `SPAN_BUDGET`) are what make it linear. They
  sit in one module that both the parser and the drawing code use. Two separate replays of the
  same rules had already drifted apart once.
- **Forms are unwrapped, not removed.** The element still counts as removed, and the certificate
  now says "the text inside a form or button is kept".
- **Deferred by owner ruling:**
  - CJK fonts: the font is several MB, and body text is affected as well as filenames.
  - MB vs MiB.
  - Combined-path memory, M4 and M6.
- **CSP is the next session's focus** (owner).
