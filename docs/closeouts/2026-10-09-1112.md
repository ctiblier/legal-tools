## Decisions Made

Owner rulings on 2026-10-08, all on the recommended option:
- move inline scripts to files, not hashes;
- turn the CF beacon off, not allow it;
- pin exact CDN file paths, not bare hosts or vendoring;
- enforce directly, with no Report-Only phase (there is no report endpoint, and headless testing covers the same ground).

Other decisions:
- **`style-src` keeps `'unsafe-inline'`.** There are about 30 `style=""` attributes and two `<style>` blocks, and injected CSS can't run code.
- **`connect-src` includes `'self'`** because `shared/pdf/fonts.js` fetches fonts. The site is static, so no same-origin endpoint accepts data.
- **Push despite the live beacon.** The owner chose to push now. The tools work, and the only cost is one console error per page until Web Analytics is turned off.
- **Cloudflare email obfuscation is active** on `/about` and injects a same-origin `email-decode.min.js`, which `'self'` allows. My first check missed it because curl did not follow the `/about.html` → `/about` redirect. The reviewer caught it.
