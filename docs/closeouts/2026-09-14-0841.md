## Decisions Made

Sixty-four rulings were recorded during execution. The complete list, with the
reasoning and the stated cost-if-wrong for each, is preserved at
**`docs/closeouts/2026-09-14-0841-sdd-ledger.md`** — it was written to a gitignored
scratch directory during the run and would have been lost with the worktree.

The ones that shaped the result:

- **Liberation + DejaVu were embedded instead of the site's brand faces** (Task 8).
  The brand faces ship as subsetted *variable* woff2; fontkit cannot embed woff2 at
  all, and a variable TTF embeds only its default instance — so there would have
  been no real bold and no real italic. An exhibit that cannot render `<b>` as bold
  is worse than one in a different typeface. Liberation also turned out to carry
  Cyrillic, which the brand faces do not.
- **Dates print verbatim everywhere**, with `date.parsed` used in exactly one
  non-test file (`filename.js`) for naming and sorting only. Normalizing a timezone
  silently alters evidence, and timezone is frequently the disputed fact.
- **Disclosure over silence was enforced repeatedly against my own plan.** Six
  separate defects were found where content vanished without a mark: images inside
  `<a>` wrappers, `<tfoot>` rows, nested list items, table captions, hyperlink
  targets, and — worst — every appended attachment in combined mode, while the
  manifest still said "appended to this PDF."
- **Tests that could not fail were the dominant failure mode of this run**, found
  six times. The rule adopted early — *if an expected value looks wrong, report it
  and leave the test failing rather than adjusting it* — caught genuine defects on
  five occasions, including one where my own test premise was wrong (DejaVu really
  does ship a glyph for U+1F600).
- **The blank spare page in the combined table of contents is deliberate.** Dropping
  the reserved page to avoid it would risk a truncated contents list, and an
  incomplete table of contents in an exhibit is worse than a blank page.
- **The certificate states the page count's scope rather than inventing a total.**
  It is drawn before the document is finalised, so the true total genuinely is not
  knowable there; the footer carries the exact count.

**Deferred minors:** 20, each recorded in the ledger with its reasoning. Notable:
`measure()` returning `NaN` would silently produce one unbroken line; `&nbsp;`

**Repo weight:** this branch adds ~4.1 MB of fonts plus ~1.5 MB of vendored
JavaScript. Justified — lazy-loaded on one page, subsetted at embed — but it is a
permanent change to a static-site repo and deserves a human's sign-off.

**Test-runner flakiness:** `run-tests` is controller scratch tooling, not a
deliverable, and lives in the gitignored workspace. Its virtual-time budget needed
raising four times; the requirement drifts with host load, so it is now set an order
of magnitude above observed need with a real `timeout 180` wall-clock guard. If the
suite is revived later, that script must be recreated — the plan's Task 1 describes
the browser invocation it wraps.
